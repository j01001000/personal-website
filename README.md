# Jun Hong's personal website

Four connected pages introduce my background, hobbies, computer graphics and
Excel projects, and experience. The resume is written in HTML and includes a
downloadable PDF.

Open `index.html` in a browser to view the site locally. Keep `views/` and
`resources/` together when moving the website. All website assets use relative
paths, and Bootstrap CSS and JavaScript are included locally.

For GitHub Pages, publish from the `main` branch and the `/ (root)` folder.

The site uses compressed WebP images with original JPEG/PNG fallbacks.
Bootstrap's license and source records are in the vendor directories.
